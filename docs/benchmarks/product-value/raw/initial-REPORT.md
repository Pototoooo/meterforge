# MeterForge 产品价值实验报告

执行日期：2026-09-11

## 执行范围

本轮先执行自动化计量可信度场景：1,000 个唯一事件、250 次重复重试、SUM 聚合、按模型分组。测试脚本为 `e2e/product/product_experiments_test.go`，目标地址由 `METERFORGE_ADDRESS` 指定，默认 `http://localhost:38888`。

| 重复抑制率 | 见测试日志 |

运行命令：

```sh
cd e2e
METERFORGE_ADDRESS=http://localhost:38888 go test -count=1 -v ./product
```

## 当前结论

实验脚本已经落到 MeterForge 项目中，但在当前报告生成时没有把未执行或失败的场景伪装成结果。接入效率、运营排障和真实支付体验需要参与者日志或正式支付环境，不能由自动化回放替代。
