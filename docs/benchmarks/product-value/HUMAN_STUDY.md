# 待执行的真人产品实验

本轮参与者为 0；此文件是招募与记录模板，不是完成记录。

## 接入效率
招募 6–8 名不熟悉实现的后端/平台人员。任务为：配置 LLM 计量、配置 ASR 计量、绑定客户并查询用量。分两组交替先后顺序，使用等价而非重复的任务，对比裸 API 文档与示例接入包。统一 30 分钟上限；超时与求助仍保留在分母，不把失败者排除后计算“成功平均耗时”。记录首次有效且客户归属正确的可查询事件时间、独立完成率和求助次数。

## 运营排障
招募 5–6 名产品/运营人员；分配客户未绑定、单位错误、负数用量、价格版本差异、重复重试和消费暂停六个剧本。比较原始日志与 MeterForge 事件查询路径，使用交叉顺序且不让同一人重复已知答案。统一任务上限，记录定位正确率、耗时、求助、误操作。故障注入恢复时间不是人的定位时间。

## 判定与简历边界
小样本只作探索性任务验证，报告 n/N 和中位数/范围，不把几个人的样本包装成总体 P95 或显著增长。目标在试测后确定；原方案 40% 改善等值未经基线支持，不作为结论。
用户理解、付费转化、留存、收入必须另有真实参与者和真实交易证据。脚本不能代替招募。
